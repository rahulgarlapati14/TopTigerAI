# TopTiger 3D mascot asset

The web interface displays the boxer in tiger selection, on the fighter card, and in Corner. It loads the bundled model from /static/tiger.glb and renders it locally with WebGL. Drag the tiger to rotate it. The finish and fighter selection carry through the onboarding flow.

The bundled model is the same static mesh as videos/base.glb. The display needs neither a separate asset copy nor a CDN connection.
